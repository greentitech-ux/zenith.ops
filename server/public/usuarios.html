Diagnóstico de anexos (Storage)

Se os anexos estiverem falhando com "Não foi possível enviar o arquivo agora", clique abaixo: o sistema testa um envio de verdade em cada bucket do Firebase Storage e mostra o erro exato de cada um.

Relatório diário do MV (e-mail)

Todo dia (RELATORIO_HORA, padrão 8h) o sistema manda um e-mail com as solicitações direcionadas ao MV, com botões de Aprovar/Recusar direto no e-mail (sem precisar logar). Use "Enviar agora" pra testar sem esperar o horário - depende de RELATORIO_EMAIL_USER/PASS/TO configurados no Render.

Relatórios de transações

A cada 2 dias o sistema gera um PDF/CSV com tudo que aconteceu no período (aprovado, recusado, estornado, chargeback, fraude...) e depois apaga do banco o que não é chargeback nem fraude suspeita - esses dois ficam guardados pra sempre pra continuar gerando alerta. Use "Gerar agora" pra rodar fora do horário automático.
